# KeyRush2 ⌨️

KeyRush2 is a full-stack typing speed application built with **Next.js, TypeScript, Supabase, and Tailwind CSS**.  
It lets users practice typing with timed sessions, track WPM and accuracy, sign in with Google, save runs, view personal stats, and compare scores on a leaderboard.

---

## 🚀 Features

- Timed typing tests with multiple modes: **15s, 30s, 45s, and 60s**
- Real-time WPM and accuracy calculation while typing
- Random typing prompts fetched from Supabase
- Google OAuth authentication using Supabase Auth
- Guest play support with optional login for saved stats
- Personal stats page for logged-in users
- Leaderboard filtered by typing duration
- Server-side run validation before saving results
- Windows 95-inspired retro UI using Tailwind CSS
